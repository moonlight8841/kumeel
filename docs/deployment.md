## Supabase

المشروع المعتمد: jigypvbqiuakdatkzoul. تحقق اتصال Auth بالمفتاح العام وتفعيل البريد، وتحميل سجل المحتوى المنشور بنجاح. الوصول المجهول إلى العضوية والمسودات مرفوض. لا يحتوي كود الواجهة على مفاتيح إدارية.

المستخدم أكد تنفيذ التهيئة وتفعيل المالك. تحققنا من تحميل المحتوى فعليًا؛ دخول حساب المالك الخاص وعضويته يتحققان بعد دخوله ولا ندّعي اختباره بكلمة مروره. اختبارات المتصفح للمسارين المخوّل وغير المخوّل تستخدم شبكة محاكاة.

أضف https://kumeel-nine.vercel.app/admin إلى Auth → URL Configuration → Redirect URLs لتعود روابط البريد إلى الموقع المنشور. ضبط قائمة التحويل يحتاج صلاحية إدارة المشروع؛ المفتاح العام لا يتيح ذلك.
