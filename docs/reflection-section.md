# قسم التأمل

يستبدل `SkyReflection` عرض الاقتباس في الصفحة الرئيسية، ويحافظ على ترتيب القسم وإعداد ظهوره في لوحة الإدارة.

- يبدأ باقتباس الموقع، ثم يعرض مقتطفات من الكتابات المنشورة مع عنوان المصدر ورابطه.
- يتغير المقتطف كل 18 ثانية أثناء ظهور القسم فقط، مع زر للتغيير اليدوي وإيقاف الحركة والتبديل.
- يحترم إعداد تقليل الحركة في الجهاز، ويتوقف عند إخفاء الصفحة.
- الخلفية مصنوعة بـCSS وتعتمد ألوان الثيم الحالي. حركة الخلفية لا تتوقف عند التبديل اليدوي للاقتباس، وتتوقف عند مغادرة القسم أو إخفاء الصفحة أو طلب تقليل الحركة.
- استُبدل Bandcamp بمشغّل YouTube الرسمي للفيديو `vqwnTNRtQ80` والقائمة `RDvqwnTNRtQ80` عبر youtube-nocookie. مكانه الأساسي صفحة «الموسيقى والفيديو» `/music` و`/en/music` مع بطاقات وبحث وتصفية للموسيقى والفيديو. يُنشأ iframe عند اختيار مقطع أو فتح المشغّل فقط؛ الإغلاق يزيله ويوقف الصوت. لا تشغيل تلقائي أو تنزيل للصوت أو جلب لصور خارجية قبل الفتح.
- لا يظهر صندوق عائم في الصفحات الأخرى قبل اختيار مقطع. عند التنقل أثناء التشغيل يتحول المشغّل إلى نافذة مصغرة ظاهرة، والعودة للقسم تعيده إلى حجمه داخل الصفحة دون تبديل iframe.
- للقسم رابط في التنقل والتذييل ومدخل في الرئيسية يمكن ترتيبه أو إخفاؤه عبر إعدادات الأقسام. الإدارة `/admin#music` تعرض اسم «الموسيقى والفيديو»، وتسمح بالتصنيف وإعادة الترتيب والإضافة والتعديل والحذف.
- المشغّل خارج مكوّن الصفحة. أثناء فتحه، روابط الصفحات العامة تجلب HTML الوجهة وتتحقق من بياناتها العامة ثم تعرض الصفحة داخل React دون إزالة iframe. يدعم الرجوع والتقدم وتحديث العنوان والروابط القانونية وبيانات SEO ولغة الصفحة. عند تعذّر التنقل يعود للتصفح التقليدي.
- التحديث الكامل وإغلاق التبويب والانتقال للإدارة أو مساحة العضو والروابط الخارجية يوقف التشغيل. لا نعد باستمرار الصوت عندما يقيّد الهاتف التشغيل في الخلفية، ولا نخفي فيديو YouTube أو ضوابطه.
- قسم الإدارة `/admin#music` يضيف ويعدل ويحذف حتى 12 مقطعًا، مع حفظ مسودة ثم نشرها عبر صلاحيات الإدارة الحالية. `site.music` اختياري للنسخ القديمة؛ غيابه يستخدم الفيديو الافتراضي، ومصفوفة فارغة تخفي المشغّل. الروابط فقط محفوظة مع المحتوى؛ لا جدول أو ملفات وسائط جديدة.
- يقبل المحرر روابط YouTube أو كود iframe، لكن يخزن رابطًا موحدًا بعد فحص المضيف ومعرف الفيديو والقائمة فقط. لا ينفّذ HTML أو معلمات autoplay المدخلة. CSP يسمح بـyoutube-nocookie فقط للتضمين، وأزيل Bandcamp.
- عنوان الفيديو «Copyright Free» ليس إثبات ترخيص. نستخدم تضمين المزوّد، ولم نتحقق من ترخيص إعادة توزيع ملفه. المزوّد قد يعرض إعلانات أو يمنع التشغيل أو يغير توفر الفيديو؛ رابط YouTube بديل ظاهر. البث يستهلك اتصال الزائر، وليس نقل الفيديو من استضافة الموقع.
- نصوص الواجهة متاحة بالعربية والإنجليزية، مع الحفاظ على لغة المحتوى الأصلي.

ملفات `/assets/*` ذات الأسماء المشتقة من المحتوى تُخدَّم مباشرة من Static Assets، مع تخزين مؤقت لمدة سنة ورؤوس حماية في `public/_headers`. الصفحات وواجهات API تستمر عبر Worker. هذا لا يلغي استهلاك الطلبات الديناميكية أو خدمات Supabase.

التحقق: `npm run verify` ثم `npm run test:published` بعد النشر، وفحص رؤوس الأصول والصفحتين العربية والإنجليزية.
