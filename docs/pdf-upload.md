# رفع الكتب وحماية الإدارة

طُبّقت migration `20261019215252_secure_admin_pdf_uploads` على المشروع السحابي.

نُشرت واجهة الرفع في Worker بالإصدار `60c6b63b-0aa4-43d7-a816-c8c16476b099` بعد نجاح الاختبارات والبناء وفحص النشر التجريبي. ورُفض طلب رفع PDF بمفتاح النشر العام دون جلسة عبر Storage HTTP بحالة `Unauthorized`/403 (الاستجابة الخارجية HTTP 400 تحمل `statusCode:403`).

## الاستخدام

1. سجّل الدخول إلى الإدارة وأكمل رمز تطبيق المصادقة.
2. افتح «مكتبة الكتب» واختر كتابًا لتحريره أو أدخل بيانات كتاب جديد.
3. اختر «رفع ملف PDF». تقبل الواجهة ملفًا حتى ٥٠ ميغابايت وتتحقق من الامتداد ونوع الملف وترويسة PDF وعلامة نهايته.
4. بعد نجاح الرفع، يُملأ الرابط والحجم الفعلي تلقائيًا. أكمل بيانات الكتاب واضغط «حفظ الكتاب».
5. راجع المسودة وانشرها من أدوات النشر السحابي. يمكن بدل الرفع إدخال رابط PDF موجود.

رفع الملف لا ينشر بيانات الكتاب. الحاوية عامة؛ يمكن فتح الملف لمن يملك رابطه فور رفعه. الإزالة من الفهرس لا تحذف الملف. قد يبقى ملف غير مستخدم إذا غادرت قبل حفظ المسودة؛ لا يحذف النظام ملفات المكتبة تلقائيًا.

## الحماية المفروضة

- قاعدة البيانات تشترط جلسة نشطة، وبريدًا مؤكّدًا، وعضوية الإدارة وقائمتها المعتمدة، ومستوى MFA `aal2`.
- الشرط يسري على النشر والمسودات وعمليات المراجعة التي تعتمد الدالة الإدارية، وعلى ملفات الصور والكتب. لا يمنح إنشاء حساب صلاحية مدير.
- رفع PDF يتم إلى `kumeel-books/books/<user-id>/<random-uuid>.pdf`؛ المسار يجب أن يطابق المستخدم. لا توجد صلاحية استبدال أو حذف من الواجهة، والرفع يستخدم `upsert:false`.
- حاوية الكتب تقبل `application/pdf` فقط وحتى ٥٠ ميغابايت. حاوية الصور تحتفظ بأنواعها وحدّها السابقين.
- فحص الترويسة والنهاية في المتصفح فحص تنسيق أولي، وليس فحص برمجيات ضارة أو تحققًا كاملًا من بنية PDF. قيود الحجم وMIME والصلاحيات في الخدمة مستقلة عن فحص الواجهة.

## التحقق

- `npm run test:auth` يشمل رفض الملفات المزيفة والمبتورة والكبيرة، ورفض البريد غير المؤكد والجلسة دون MFA، وصحة المسار والرابط والحجم وعدم الاستبدال.
- `supabase/tests/pdf-storage.sql` نجح على القاعدة السحابية. يستخدم جلسة وبيانات تخزين اصطناعية داخل transaction تتراجع بالكامل؛ يثبت قبول المدير بمستوى `aal2` ورفض `aal1` والمسار المخالف والجلسة الملغاة. لا ينشئ جلسة مستخدم فعلية أو ملفًا دائمًا.
- `python scripts/check-pdf-storage.py` رفع PDF اصطناعيًا عبر Storage HTTP، وحمّله وتحقق من MIME ومطابقة البايتات ثم حذفه. هذا اختبار نقل بمفتاح خدمة؛ اختبارات RLS منفصلة أعلاه. تحقق SQL من أن عدد ملفات الاختبار المتبقية صفر.
- لم يُستخدم رمز المصادقة أو جلسة المتصفح الخاصة بالمالك لاختبار رفع تفاعلي. رفع ملف من الحساب داخل الواجهة هو التحقق النهائي لتلك التجربة.

## ما زال خارج هذا الإصلاح

مهلة خمول الإدارة (١٥ دقيقة) في المتصفح؛ ليست مهلة خادم. حماية كلمات المرور المسرّبة ما زالت مرفوضة برمز 402. لقطة schema محفوظة، لكن إعادة بناء قاعدة جديدة واختبار استعادتها ما زالا غير متحققين. الدوال المصرح بها للعملاء أو بسر الخادم ما زالت تحتاج مراجعة دورية؛ هذه التغييرات لا تمثل ضمانًا مطلقًا للأمان.
